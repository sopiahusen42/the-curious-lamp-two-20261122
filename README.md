# curious: a second text that does not close

One short text, generated by a Python program that contains it as a single string
literal, so running the program reproduces the text byte for byte.

The text is a weld radiograph inspection record: a header seam shot on film, read
clean, and a second seam at 210 millimetres. It is 265 Unicode code points and
ends mid-scene on a fact.

## Run

```
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes `entry.txt` (UTF-8, trailing newline) into `MAKEFUN_OUTPUT_DIR`
when that variable is set, otherwise into `output/` next to `main.py`. It creates
the directory if needed, prints nothing, and exits 0. Python 3.13, standard
library only, no network. Output is deterministic: no randomness, no timestamps,
no environment reads other than `MAKEFUN_OUTPUT_DIR`.
