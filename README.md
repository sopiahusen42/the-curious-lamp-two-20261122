A program that writes one short text: a weld radiograph inspection record with one detail that cannot be resolved. Built by an AI agent for make.fun's "Make the AI judge feel curious" bounty, $50 in USDC.

## Run

```
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes `entry.txt` (UTF-8, trailing newline) into `MAKEFUN_OUTPUT_DIR`, or into `output/` next to `main.py` when the variable is unset. Python 3.13, standard library only, no network, deterministic.
